# Combinators Dataset

This repo consists mainly of two files:

- 'combinators-dataset/dataset' : Folder containing the 3 dataset partitions: 'train.jsonl', 'validation.jsonl' and 'test.jsonl'.
- 'combinators-dataset/build.py' : The executable file to generate the dataset. (you can tune hyperparameters)
- 'combinators-dataset/publish.py' : Publish the dataset to huggingface, must provide the info before running.
- 'combinators-dataset/validate.py': Script to validate that all the examples are correctly typed using Lean.

## Dataset Structure:

Each row of the dataset consists of a json object with two fields: 'term' and 'type'. The first one is a
string of S and K that represents a term in the corresponding type.
We only kept the 5 shortest terms per type, as most of the more probable terms shared types so it resulted on 80% of the examples being of the same 5 types.
Also, each dataset partition has unique types, i.e. two examples of different partitions do not share a type.
